# Расследование прекращения потока

## Порядок проверки

1. Зафиксируй фактическое окно и получи `source_info`.
2. Проверь объём и динамику через `count_events` и `timeline`.
3. Сравни с соседними сопоставимыми окнами, не объявляй обычное затишье отказом.
4. Проверь источник без чрезмерно узкого фильтра.
5. Различай время события и время приёма или индексации.

## Дискриминирующие проверки

- Если события есть по source time, но отсутствуют по receive time, проверяй конвейер приёма.
- Если события приходят пачкой с одинаковым receive time, рассмотри replay/backfill.
- Если отсутствуют только определённые типы событий, проверяй фильтрацию и нормализацию.

## Ограничения

Отсутствие событий в выбранном окне и фильтре не доказывает отсутствие потока вообще. Каждый вывод подтверждай свежими Evidence из LogiCore.
