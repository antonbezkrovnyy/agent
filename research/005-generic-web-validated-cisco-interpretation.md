# R005 — интерпретация без Cisco-specific prompt

> Повторная проверка R004 после удаления из prompt явных упоминаний Cisco и RFC. Модель должна самостоятельно определить предметную область и найти документацию.

## Краткий результат

**Обобщённый prompt не помешал модели распознать Cisco ASA и собрать структурированное событие. Однако модель выполнила несколько десятков поисковых вызовов, многократно уточняя одни и те же обозначения.**

## Оценка

Удаление Cisco-specific инструкций не разрушило результат: модель сама выбрала релевантные поисковые запросы и восстановила событие. Это положительный сигнал для универсальности контура.

Одновременно проявился операционный дефект: при неудачной выдаче модель многократно повторяла близкие запросы вместо ранней остановки с явным `unknown`. Поэтому качество ответа и стоимость исследования нужно оценивать раздельно.

## Вывод

**Общий prompt пригоден для самостоятельного распознавания формата, но следующему эксперименту нужны лимит поисковых вызовов, дедупликация запросов и ранняя остановка при отсутствии доказательств.**
