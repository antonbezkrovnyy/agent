## Итоговая спецификация

### Структура

Модель разделила:

- syslog-подобный header: PRI, timestamp, host, separator;
- message: mnemonic и body;
- составные endpoints: interface, address, port;
- счётчик и opaque-ссылку first hit.

Рекурсивное декодирование и unescape не применяются без наблюдаемого слоя. Это соответствует общей задаче для вложенных и кастомных форматов.

### Поля результата

| Группа | Поля |
|---|---|
| RAW и residual | `raw`, `residual` |
| Конверт | `timestamp_raw`, `host` |
| Диспетчер | `msg_id` |
| Событие | `severity`, `acl_name`, `action`, `protocol` |
| Source | `src_interface`, `src_address`, `src_port` |
| Destination | `dst_interface`, `dst_address`, `dst_port` |
| Агрегация | `hit_cnt`, `first_hit_ref` |

PRI присутствует в `structure` и по решению модели сохраняется в `residual` без декодирования. Это не противоречит запрету вычисляемых полей.

### Стратегия

Стратегия содержит только решения, включая:

- выделять Family по стабильному `msg_id`;
- не включать dynamic severity в ключ;
- считать конверт опциональным;
- разбирать body по наблюдаемым якорям;
- разбирать endpoint как вложенную конструкцию;
- сохранять RAW и residual;
- не декодировать непрозрачную hex-пару;
- не подменять отсутствие нулём.

## Оставшиеся вопросы, а не блокеры

### Обязательность портов и first_hit_ref

В текущем результате `src_port`, `dst_port` и `first_hit_ref` имеют `required=true`. Для конкретной показанной строки это соответствует входу. Перед обобщением на другие варианты Family нужно отдельно подтвердить, обязательны ли они для всех форм записи.

Это не противоречит текущему примеру, но требует проверки при расширении контракта.

### Тип адреса

Адреса оставлены строками, а не объявлены жёстко `ip` по одному IPv4-наблюдению. Это корректная осторожность для неизвестного формата.
